Claude Haiku 5.5
Pricing

The complete cost guide for both prompt-length tiers, cache reads and writes, Amazon Bedrock, Batch API and regional inference—with worked examples you can audit.

THE SHORT ANSWER

$0.10 input and $0.50 output per million tokens—until the prompt exceeds 100K.

For prompts over 100,000 tokens, Haiku 5.5 rises to $0.50 per million input tokens and $2.50 per million output tokens. The threshold is evaluated per request, not from your monthly token total.

02 / THE 100K RULE

The threshold applies to each request.

It is not a monthly volume threshold.

At or below 100K

  • Input: $0.10 / MTok
  • Output: $0.50 / MTok
  • Cache read: $0.01 / MTok
  • Best unit economics for short, high-volume work

Over 100K

  • Input: $0.50 / MTok
  • Output: $2.50 / MTok
  • Cache read: $0.05 / MTok
  • Still lower list price than Haiku 4.5 at equal token counts
Boundary case:

Anthropic describes the lower tier as prompts “up to 100,000 tokens” and the higher tier as prompts “over 100,000 tokens.” Exactly 100,000 prompt tokens therefore remain in the lower tier.

04 / DISCOUNTS & MODIFIERS

Three settings can change the bill.

Pricing modifiers may stack, so model the full request configuration.

−50%

Batch API discount on input and output tokens for asynchronous processing.

0.1×

Haiku cache-hit multiplier versus the applicable base input rate.

1.1×

US-only inference multiplier for Claude 4.6 and later models; global routing uses standard pricing.

A five-minute cache write costs 1.25× the base input rate and a one-hour write costs 2×. Caching pays off when reused prompt content avoids repeated full-price input processing.

07 / FAQ

Claude Haiku 5.5 pricing questions

How much does Claude Haiku 5.5 cost?

Prompts up to 100K cost $0.10 per million input tokens and $0.50 per million output tokens. Prompts over 100K cost $0.50 input and $2.50 output at the Global base rate.

Does exactly 100K use the lower tier?

Yes. Anthropic’s rate card says “up to 100,000 tokens” for the lower tier and “over 100,000 tokens” for the higher tier.

How much does prompt caching cost?

In the Global short tier, a five-minute write is $0.125/MTok, a one-hour write is $0.20/MTok and a cache hit is $0.01/MTok. In the long tier they are $0.625, $1.00 and $0.05 respectively.

Does Batch API cut the price?

On the Claude Platform, yes: Anthropic documents a 50% input and output discount. The current Amazon Bedrock model card marks Batch unsupported for Haiku 5.5, so do not apply the discount to Bedrock workloads.

How much is Haiku 5.5 on Amazon Bedrock?

Global cross-Region inference uses the base rates. US Geo cross-Region inference is 1.1×: for prompts up to 100K, that is $0.11 input and $0.55 output per million tokens; above 100K, $0.55 input and $2.75 output.

Are Amazon Bedrock and Claude Platform on AWS the same?

No. Bedrock is AWS-managed model access with Bedrock IDs and features. Claude Platform on AWS is Anthropic’s native API and console experience with AWS billing and authentication.

What is the Haiku 5.5 model ID?

Use claude-haiku-5-5 on the Claude Platform and anthropic.claude-haiku-5-5 on Bedrock. Cross-Region Bedrock profiles add a scope prefix such as global. or us..
