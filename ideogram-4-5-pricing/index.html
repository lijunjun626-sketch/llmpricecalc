Ideogram 4.5
Pricing

Ideogram 4.5 API pricing runs from $0.008 to $0.22 per image. Use this calculator to compare Generate, generation with source images and Precise Edit at official quality-tier rates.

THE SHORT ANSWER

Most standard generations cost $0.03–$0.10 per image.

Medium quality is $0.06. High-quality generation without a source image is $0.10, while High generation with source images and High Precise Edit are $0.22. The lowest $0.008 tier applies to source-image generation and Precise Edit—not ordinary text-to-image generation.

04 / WHAT YOU ARE BUYING

Generation and precision editing solve different jobs

Generate

Use text-to-image generation for new concepts, marketing visuals, product mockups and typography-heavy compositions. Low and Medium tiers are the economical defaults for iteration.

Precise Edit

Use Precise Edit when the source image must remain recognizable while a targeted region or instruction changes. Ideogram highlights reduced drift over multiple editing turns.

Ideogram app subscriptions and API billing are separate. App plans use priority credits; they should not be converted into API rates. For production estimates, use the API table and monitor the official pricing page for changes.

05 / FAQ

Ideogram 4.5 pricing questions

How much does Ideogram 4.5 cost per image?

Official API prices range from $0.008 to $0.22 depending on operation and quality. Standard no-source generation starts at $0.03.

Does 2K cost more than 1K?

No difference is listed in the official Ideogram 4.5 API table: 1K and 2K share the same price within a quality tier.

What does Precise Edit cost?

$0.008 at Very Low, $0.03 at Low, $0.06 at Medium and $0.22 at High per image.

Are app subscriptions included?

No. Ideogram app plans use credits, while API use is separately billed.

What rate limit should I expect?

Ideogram documents a default limit of 10 in-flight API requests. Check your account and current documentation before designing production concurrency.
