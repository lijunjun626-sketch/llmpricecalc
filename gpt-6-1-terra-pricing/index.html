03 / DECISION

Choose the model for the job, not only the price.

Try Terra for

  • Visual reasoning and document or screen interpretation
  • Defined computer-use workflows
  • Scoped coding fixes and concise writing
  • High-volume work where token cost matters

Consider Sol or Astra for

  • Ambiguous or long-horizon reasoning
  • Complex software projects
  • Tasks where quality has more value than token savings
  • Workloads that need a larger capability margin
Cost note:

The calculator compares published text-token prices. It does not estimate charges for tools, images, search, computer use, regional processing, or an application’s own infrastructure.

04 / FAQ

GPT-6.1 Terra pricing answers

How much does GPT-6.1 Terra cost?

Standard token pricing is $1.00 per million input tokens, $0.05 cached input tokens, and $5.00 output tokens.

Is Terra exactly half the price of Sol?

For the published standard text-token input, cached-input, and output rates, yes. Your application’s total bill can still differ because tools and other modalities have separate prices.

Can I use Batch or Flex pricing?

OpenAI documents Batch and Flex pricing as 50% lower than standard token rates. Use the calculator switch to model the token-price difference.

Where do these prices come from?
