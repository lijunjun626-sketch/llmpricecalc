04 / FAQ

Claude Fable 5.2 pricing answers

How much does Claude Fable 5.2 cost?

Standard is $8 input and $40 output per million tokens. Fast is $16 and $80. Batch is $4 and $20. Standard cache hits are $0.20, 5-minute writes are $10, and 1-hour writes are $16.

Does the US multiplier apply to cache tokens?

Yes. For Claude 4.6 and later models, inference_geo: "us" is 1.1 times every token category, including cache reads and cache writes. Global routing stays at the base rates.

Can I use Fast and Batch together?

No. Fast mode is not available with the Batch API.

Is Mythos 5.2 included?

No. Mythos 5.2 is not publicly available. Access is limited to Anthropic's verification programs. This page prices claude-fable-5-2 only.

Is this Anthropic's calculator?

No. It is an independent reading of the published Claude Platform rates. Partner clouds can set different prices. Confirm the current pricing page before production use.
