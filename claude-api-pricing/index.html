04 / FAQ

Claude API pricing questions

How is Claude API cost calculated?

Multiply input and output token counts by their respective per-million-token rates, then add cache and provider-specific charges.

Which Claude model is cheapest?

Haiku has the lowest displayed token rates. The cheapest model per completed task can differ when retries, output length and quality requirements are included.

Does prompt caching reduce Claude cost?

It can reduce repeated-input cost when the workload meets the provider’s caching rules. Cache writes and reads have separate rates.

Are AWS Bedrock and Vertex AI prices identical?

Do not assume so. Verify the rate card for the exact platform and region you deploy to.

How often should I verify API prices?

Check the official provider page before launch and whenever a model, context tier or hosting route changes.
