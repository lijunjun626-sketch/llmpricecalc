03 / HOW TO COMPARE

Price per token is only the starting point.

Model the whole request

Separate uncached input, cache writes, cache reads and generated output. Long prompts can trigger another rate tier.

Measure accepted-task cost

Divide spend by usable answers, resolved tickets or accepted patches—not raw request count.

Record route and date

The same model can differ across first-party and aggregator routes.

04 / FAQ

LLM API pricing questions

How do I calculate LLM API cost?

Divide input and output tokens by one million, multiply each by its rate, then add caching, tool, image, regional or provider-specific charges.

What is the cheapest LLM API?

There is no universal answer. Low token rates can lose their advantage when a workload needs more output, retries or escalation.

Why can two sites show different prices?

They may refer to different providers, regions, prompt-length tiers, cache rules or verification dates.

Should I choose a model using benchmarks?

Use benchmarks to shortlist candidates, then test your own prompts and acceptance criteria. Separate independent results from vendor claims.
