04 / QUICK ANSWERS
Questions users ask before using project instruction files.
What is a CLAUDE.md generator?
It creates a starting Markdown file containing a project’s commands, architecture notes, and working rules. Review it before committing: a generator cannot know hidden project details.
What should I enter into the generator?
Enter stable project facts: the stack, package manager, deployment target, and boundaries such as whether an agent may add dependencies or rewrite Git history.
Why generate AGENTS.md or GEMINI.md too?
Different coding assistants use different project-instruction conventions. This tool provides equivalent starting files so teams can maintain consistent rules.
Is my project information sent to an AI model?
No. This version creates Markdown from local form choices. It does not upload your project description or invoke an AI API.
